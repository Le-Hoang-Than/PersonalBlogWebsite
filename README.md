Thành phần tái sử dụng:
- /components/                  : Navbar, footer, form feedback dùng chung
- /assets/css/                  : CSS từng phần + style chung
- /assets/js/                   : Script JS từng phần + script chung
- /data/tags.json               : Metadata (title, path, tags...)

Công nghệ:
- HTML, CSS, JavaScript
- jQuery (cho feedback và xử lý dữ liệu từ JSON)
- JSON (lưu metadata)

Ghi chú:
- Sử dụng JavaScript hoặc jQuery để load nội dung động từ `db`
- Có thể mở rộng với các framework như React, Vue trong tương lai

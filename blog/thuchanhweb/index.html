Các tính năng nổi bật của trang web

Trang blog

  1. Sử dụng scss, chỉ biên dịch một file main.scss thành css và link vào html.
  2. main.scss sẽ import các file _style.scss và các file .scss khác.
  3. Trước khi các tài nguyên tải xong sẽ xuất hiện loading screen
  4. Thanh navbar tự động ẩn hiện khi cuộn.
  5. Trang được thiết kế sử dụng jquery để load các component vào trang html.
  6. Trang được thiết kế sử dụng jquery để bắt api ở backend tạo dữ liệu động vào các component trong trang html.
  7. Sử dụng api key của sendgrid để gửi mail xác nhận phản hồi từ token

Trang portfolio

  1. Thiết kế và tài nguyên tách biệt hoàn toàn so với project, dễ tách thành trang riêng.
  2. Navbar ở desktop sẽ ở trên top.
  3. Navbar ở tablet, mobile sẽ ở dưới bottom, tự động active khi cuộn đến vị trí.

Trang quản trị

  1. Đăng nhập bằng cách xác thực qua email, khi nhập đúng thông tin đăng nhập(sử dụng api key sendgrid).
  2. Thiết kế sidebar ẩn hiện ở bên trái, khi hover sidebar mở rộng.
  3. Quản lý danh mục, bài viết,... bằng php thuần.
  4. Sử dụng thư viện editorjs để thao tác đăng bài.
